# MLiev IAM 品牌 Logo

本目录保存 MLiev IAM 的正式品牌 Logo 源文件及使用信息。

## 设计含义

- 几何字母 `M` 延续原 OIDC favicon 的识别特征。
- 中央钥匙孔代表身份主体，贯穿其中的通道代表统一认证和访问入口。
- 蓝色结构表示身份流转与联邦认证，深蓝立柱表示稳定的安全边界。
- 图形轮廓针对登录卡片、后台侧栏与 favicon 等小尺寸场景进行了简化。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `mliev-iam-mark.svg` | 透明背景的主图形标志，适合页面品牌区和文档 |
| `mliev-iam-app-icon.svg` | 深色圆角底应用图标，适合 favicon、桌面图标和头像 |
| `mliev-iam-lockup.svg` | 图形、产品名和英文说明的横向组合，适合页头和对外资料 |

## 标准色

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| Identity Blue | `#2563EB` | 主品牌色、身份流转 |
| Security Navy | `#0F172A` | 安全边界、主文字 |
| Slate | `#475569` | 辅助文字 |
| Surface | `#F8FAFC` | 深色背景上的标志前景 |

## 使用规则

- 优先使用 SVG 源文件；需要 PNG 或 ICO 时从对应 SVG 导出。
- 标志四周至少保留图形宽度 `1/8` 的安全留白。
- 不拉伸、不旋转、不增加渐变、描边、发光或投影。
- 浅色背景使用 `mliev-iam-mark.svg`，应用图标和极小尺寸优先使用 `mliev-iam-app-icon.svg`。
- 横向组合中的字体优先使用 Inter；系统无 Inter 时使用系统无衬线字体。
