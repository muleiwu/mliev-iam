# 数据库种子数据说明

## 概述

系统在首次运行数据库迁移时会自动初始化种子数据，包括默认部门、角色、权限和管理员账户。

## 默认数据

### 1. 默认部门结构

- **系统管理** (system)
  - 类型：公司级别
  - 状态：启用
  - 数据权限：全部数据权限
  - 子部门：
    - **管理员** (admin)
      - 类型：部门级别
      - 状态：启用
      - 数据权限：全部数据权限

### 2. 默认角色

- **超级管理员** (super_admin)
  - 类型：系统角色
  - 状态：启用
  - 数据权限：全部数据权限
  - 描述：系统超级管理员，拥有所有权限

### 3. 默认权限

系统会创建以下基础权限：

1. **系统管理** (system:manage)
   - 类型：菜单权限
   - 资源：system，操作：*（所有操作）

2. **用户管理** (user:manage)
   - 类型：菜单权限
   - 资源：user，操作：*（所有操作）

3. **角色管理** (role:manage)
   - 类型：菜单权限
   - 资源：role，操作：*（所有操作）

4. **部门管理** (department:manage)
   - 类型：菜单权限
   - 资源：department，操作：*（所有操作）

5. **权限管理** (permission:manage)
   - 类型：菜单权限
   - 资源：permission，操作：*（所有操作）

### 4. 默认管理员账户

- **用户名**: `admin`
- **密码**: `admin123`
- **邮箱**: `admin@example.com`
- **昵称**: `系统管理员`
- **真实姓名**: `系统管理员`
- **状态**: 激活
- **部门**: 管理员部门
- **角色**: 超级管理员
- **权限**: 拥有所有系统权限

## 安全建议

⚠️ **重要安全提示**：

1. **首次登录后请立即修改默认管理员密码**
2. **建议创建新的管理员账户后删除默认账户**
3. **不要在生产环境中使用默认密码**

## 种子数据逻辑

种子数据初始化会在以下情况下执行：

1. 数据库迁移成功后
2. 检查到 `users` 表为空时
3. 如果已有用户数据，则跳过种子数据初始化

## 自定义种子数据

如需自定义种子数据，请修改以下文件：

```
internal/service/migration/migration.go
```

可以在以下方法中修改相应的默认数据：

- `createDefaultDepartment()` - 修改默认部门
- `createDefaultRolesAndPermissions()` - 修改默认角色和权限
- `createDefaultAdmin()` - 修改默认管理员账户

## 故障排除

如果种子数据初始化失败，请检查：

1. 数据库连接是否正常
2. 数据库用户是否有足够的权限
3. 模型定义是否正确
4. 外键约束是否满足

查看系统日志获取详细错误信息。
