# MLiev IAM 项目结构和主要功能分析

## 项目概述

MLiev IAM 是一个基于 Go 语言开发的现代化企业级身份认证与访问管理（IAM）系统，集成了单点登录（SSO）功能。该项目采用前后端分离架构，后端使用 Go + Gin 框架，前端使用 Vue 3 + Ant Design Vue。

## 技术架构

### 后端技术栈
- **编程语言**: Go 1.25+
- **Web框架**: Gin
- **数据库**: MySQL/PostgreSQL/SQLite (使用 GORM v1.31.0)
- **缓存**: Redis
- **配置管理**: Viper
- **日志**: Zap
- **认证协议**: JWT、OAuth2.0、OIDC、SAML、CAS
- **容器化**: Docker

### 前端技术栈
- **框架**: Vue 3 + TypeScript
- **UI组件**: Ant Design Vue
- **构建工具**: Vben
- **状态管理**: Pinia
- **路由**: Vue Router
- **HTTP客户端**: Axios

## 项目结构


## 核心功能模块

### 1. 用户管理
- **用户生命周期管理**: 注册、激活、禁用、锁定
- **用户信息管理**: 基础信息、认证信息、状态管理
- **密码管理**: 加密存储、重置、过期策略
- **登录统计**: 登录次数、失败计数、最后登录时间

### 2. 角色权限管理 (RBAC)
- **角色管理**: 系统角色、自定义角色、层级结构
- **权限管理**: 菜单权限、按钮权限、API权限、数据权限
- **数据权限**: 全部数据、本部门、本部门及下级、仅本人
- **权限继承**: 基于层级路径的权限继承机制

### 3. 组织架构管理
- **部门管理**: 多层级组织架构、部门类型（公司/事业部/部门/团队）
- **层级维护**: 自动维护父子关系和层级路径
- **负责人管理**: 部门负责人设置
- **数据权限隔离**: 部门级数据权限控制

### 4. 应用管理 (多协议支持)
- **OIDC 应用**: OpenID Connect 协议支持
- **SAML 应用**: SAML 2.0 协议支持
- **CAS 应用**: CAS 协议支持
- **OAuth2 应用**: OAuth 2.0 协议支持
- **密钥管理**: 密钥轮转、客户端密钥重置

### 5. 身份认证
- **多种认证方式**: 用户名密码、社交登录
- **OIDC 流程**: 授权码、隐式、混合流程
- **令牌管理**: JWT 令牌、刷新令牌、令牌撤销
- **会话管理**: Redis 会话存储

### 6. 社交登录集成
- **多平台支持**: 支持多种 OAuth2.0 提供商
- **账号绑定**: 社交账号与系统用户绑定
- **自动注册**: 社交登录自动创建用户

### 7. 系统管理
- **系统安装**: 数据库初始化、管理员创建
- **配置管理**: 热重载配置、多环境配置
- **健康检查**: 数据库、Redis 连接状态检查
- **日志管理**: 结构化日志、操作审计

## 数据模型设计

### 核心实体关系
```
用户(User) ←→ 用户角色(UserRole) ←→ 角色(Role) ←→ 角色权限(RolePermission) ←→ 权限(Permission)
     ↓                                        ↓                                                    ↓
  部门(Department)                        层级结构                                            资源控制
```

### 主要模型特性
- **用户模型**: 状态管理、多属性、认证安全、部门关联
- **角色模型**: 层级结构、数据权限范围、系统/自定义角色
- **权限模型**: 多类型权限、资源控制、层级继承、前端集成
- **部门模型**: 组织架构、层级管理、负责人、成本中心
- **应用模型**: 协议无关设计、多协议支持、配置化

## 开发指南

### 环境要求
- Go 1.25+
- MySQL 8.0+ / PostgreSQL 13+ / SQLite 3+
- Redis 6.0+
- Node.js 18+ (前端开发)

### 快速开始
1. 克隆项目
2. 配置环境 (`cp config.yaml.example config.yaml`)
3. 安装依赖 (`go mod download`)
4. 运行项目 (`go run main.go`)

### 前端开发
```bash
# 安装依赖
make install-frontend

# 开发模式
make dev

# 构建前端
make build-frontend
```

### 后端开发
```bash
# 运行后端
make run-go

# 构建后端
make build-go
```
