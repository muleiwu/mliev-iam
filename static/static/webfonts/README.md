# Homepage fonts

`iam-puhuiti-regular.woff2` and `iam-puhuiti-bold.woff2` are web subsets of Alibaba PuHuiTi 2.0, weights 55 Regular and 85 Bold. Copyright © 2020–2021 Alibaba (China) Co., Ltd. All rights reserved. The fonts retain their original copyright and naming metadata.

Official source and usage information: https://www.alibabafonts.com/

Downloaded from the official site's font assets:
- https://fonts.alibabadesign.com/AlibabaPuHuiTi-2/AlibabaPuHuiTi-2-55-Regular/AlibabaPuHuiTi-2-55-Regular.woff2
- https://fonts.alibabadesign.com/AlibabaPuHuiTi-2/AlibabaPuHuiTi-2-85-Bold/AlibabaPuHuiTi-2-85-Bold.woff2

The subsets contain homepage text from `templates/*.html` and `app/controller/index_controller.go`, printable ASCII, ✓ and ©. They were generated with fontTools, preserving all name records and WOFF2 output. When the homepage copy changes, regenerate the subsets with the new characters; the CSS provides local Chinese font fallbacks for other text.

The pre-existing `fa-*` font files belong to Font Awesome and are unrelated to these homepage fonts.
