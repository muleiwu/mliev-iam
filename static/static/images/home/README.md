# Homepage artwork

Source: the user-provided MasterGo design, file `199699779279775`, page `M`, layer `56:00187`.
Reference: https://mastergo.com/goto/Wfy49tu7?page_id=M&layer_id=56:00187&file=199699779279775

The original raster images were extracted from MasterGo's SVG export. WebP assets retain the original artwork, with decorative icons resized to at most 400px and encoded at quality 92. The two logo SVGs and favicon retain the design's vector paths. `ui-icons.svg` contains the small interface icons used by buttons.

The original canvas is 1920 × 5270px (its exported artwork extends to 5275px). At desktop size the content width is 1400px. Text, cards and controls are implemented as HTML/CSS; no page section is a flattened screenshot.
